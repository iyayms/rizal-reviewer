# SANA PO MAKAPASA – Rizal Reviewer
Static quiz site (no build step). Files: `index.html`, `data.js` (generated from the reviewer .docx), `vercel.json`.

## Deploy
1. Push this folder to a GitHub repo → vercel.com → Add New Project → Import → Deploy (Framework: Other).
2. Or: `npm i -g vercel && cd rizal-reviewer && vercel --prod`.
